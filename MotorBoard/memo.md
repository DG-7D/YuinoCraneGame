# PWMの出し方

サーボはパルス幅が変動してはいけないのでハードウェアで出す必要がある、TCBは1チャンネルしかないのでTCAを使う必要がある。OVF割り込みのタイミングでCMP更新などすれば滑らかな動きも容易に実装できる

もたどらはソフトウェアでもよいが、周波数が高いほうがうれしいかもしれない。

## もたどらをTCBで出す場合

TCAは3チャンネルあるのでサーボ信号はハードウェアで出せる、周波数は16MHz / 4分周 / 2^16カウント = 61 Hzか16MHz / 8分周 / 40000カウント = 50 Hz

TCBは1チャンネルしかないのでもたどらはソフトウェアPWMすることになる、TCBはOVF割り込みがないのでカウンタをポーリングすることになる

## もたどらもTCAで出す場合

TCAは分割動作なら6チャンネルあるので、サーボともたどら信号両方をハードウェアで出すこともできる。ただし、周波数は両方同じになる

8ビットになるので周波数は16MHz / 1024分周 / 2^8カウント = 61 Hzか8MHz / 1024分周 / 156カウント = 50 Hzになる。後者は128us刻みでサーボがかくかくするかも
